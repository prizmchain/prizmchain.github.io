Threads data deletion

PRIZM Marketing OS is an owner-operated local marketing tool. Threads credentials and fetched working data are stored on the owner's Mac, with credentials protected by VaultX.

  1. Remove PRIZM Marketing OS under Threads → Settings → Website permissions.
  2. Delete the Threads fields from the local PRIZM Marketing OS credential in VaultX.
  3. Delete generated campaign and analytics files from the local marketing workspace.

Removing the website permission immediately prevents further API access.
